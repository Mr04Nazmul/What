About Japan Life

This is a working mobile web app. On-device Japanese OCR is available; the letter analysis uses documented keyword/date rules. A separate OpenAI-powered chat is not active because a secure server key and billing setup have not been configured. Do not upload private letters to untrusted services.
Install to iPhone Home Screen

In Safari, tap Share → Add to Home Screen.

Free sources

Tesseract.js for OCR, JavaScript for shift calculations, GitHub Pages for hosting. No paid provider needed for the active functions.

Optional cloud account

Supabase Japan Life tables created with row-level security; no login or automatic sync is enabled on this frontend yet.
